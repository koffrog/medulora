# Статус проекта MEDstudy

## Архитектура
- **Стек**: React, Vite, JavaScript, CSS (inline styles для MVP), React Router.
- **Хранилище**: localStorage (для прогресса и пользовательских данных).
- **Дизайн**: Светлый минималистичный medical-дизайн, акцентный синий цвет (#2563eb), адаптивность под мобильные устройства.

## Структура файлов
- src/components/ (общие UI-компоненты: Header, Sidebar)
- src/data/subjectsData.js (структура предметов и тем)
- src/pages/ (страницы приложения)
- PROJECT_STATUS.md (журнал проекта)
